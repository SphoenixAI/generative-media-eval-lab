# Gold-set contract: deferred Phase 6

No gold records are created by the Phase 4 demo. `judge_disagrees` is an authored reference scenario, not an adjudicated gold example. Human fixtures cannot become gold because they were easy to reproduce.

A future GoldExample must pin run, rubric, target dimension and anchor; include actual observable evidence, independent calibrated ratings, disagreement distribution, adjudication record where relevant, isolation rationale, counterexample and intended population. “Gold” means a qualified reference for a defined use, not infallible truth.

Separate development examples, visible calibration/canary examples and locked audit examples. Split by prompt and media lineage, including derivatives and near duplicates. Log exposure. When a reference is revised, retain the previous version, rationale and impact on earlier results. Unknown or irreducibly subjective examples must preserve their uncertainty rather than be forced into one numeric label.
