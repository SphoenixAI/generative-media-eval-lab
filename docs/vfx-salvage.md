# Production salvage contract: deferred Phase 8

Phase 4 includes an editability rubric dimension, repair scenario records, and a `VFXSalvageAgent` name. The specialist only emits a synthetic score and `UNKNOWN` fixability. Geometry catastrophe can trigger the provisional scoring recommendation `REGENERATE`. This is not an implemented VFX cost engine or evidence of professional repair feasibility.

A useful later assessment joins intended shot requirements to observed defect, protected content, possible intervention, expected preserved/compromised intent, effort range, required tools/skills and unresolved risk. Distinguish `POST_FIXABLE`, `EXPENSIVE_POST_FIX`, `REGENERATE` and insufficient evidence. Test repair recommendations against actual artist interventions, recording active time, success, rework and output quality. Crop/stabilize may remove an artifact while breaking the required framing; evaluating that tradeoff requires intent-aware relations.
