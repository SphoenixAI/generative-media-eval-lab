# Embed contract

`serialize_case(..., mode="embed")` is a projection of the same case, round and ratings used by public mode. Tests verify equivalent contents apart from mode. It preserves delayed reveal and never invents a second data set.

The future `/embed/case/{slug}` interaction should present A/B, request a decision and observed failures, then reveal the visitor judgment, Sphoenix judgment, qualified human distribution, instrument outputs and unresolved disagreement. A short evidence/hypothesis/test walkthrough can follow, linking to the full lab and source. At Phase 4 there is no browser component, playable clip, public rating endpoint or Sphoenix-authored real-media judgment.
