## Plan

### Goal and relevance to NORTH_STAR.md

Split L12 into bounded, sequential implementation steps that deliver an offline, read-only lint audit with an explicit evidence prerequisite contract for every rule. The final workflow must expose `eval-pilot lint DATASET`, prevent readiness when the audit has errors or unavailable/corrupt prerequisites, and retain the ruleset version and results in new private snapshots. This supplies the lint-to-snapshot stage of `loop/NORTH_STAR.md` and makes the first human-authored cases structurally auditable. It does not establish that their observations, causal explanations or acceptability judgments are correct.

This is a planning-only call. Write this report and `loop/reports/STEP-0020-split.toml`; leave implementation, product probes, test execution, plan sealing and loop bookkeeping to their prescribed phases. The split is proposed through the existing mechanism, not applied by this call.

### Acceptance criteria

Copied verbatim, in order, from L12 in `loop/backlog.toml`:

1. one TEST-ONLY graph that triggers each rule exactly once, and a clean graph that passes.
2. Every lint rule declares all evidence fields it requires, and every prerequisite passes through one shared evidence-availability boundary before it may support a clean rule result.
3. The shared evidence boundary returns AVAILABLE(value), UNKNOWN(reason) for missing, null or unavailable evidence, or INTEGRITY_FAILURE(reason) for malformed, wrong-type, impossible, corrupt or integrity-invalid evidence. Do not introduce a new INVALID vocabulary.
4. Only AVAILABLE may support a clean rule result. UNKNOWN and INTEGRITY_FAILURE each produce an explicit diagnostic and make the result incomplete/not-ready; neither can produce PASS, COMPLETE, SHIP, ready=true or an equivalent clean state.
5. One shared parameterized evidence contract test covers every declared prerequisite of every lint rule with missing, null, malformed/wrong-type where representable, and a valid boundary value. Where ordinary admission prevents malformed values, test the raw/read-only path that encounters corrupt retained data.
6. Regressions cover null and invalid motion dimensions and null and invalid decoded durations with full-clip evidence, through direct and retained-query paths, with explicit diagnostics and ready=false; valid non-motion context remains supported.
7. Use the existing split mechanism if L12 cannot fit the configured 900 changed-line budget. Never remove, loosen or reduce tests to fit.

### Shared evidence contract and rule coverage

L12-A's registry must list every field and dependency path actually read by each rule, including applicability discriminants, collection elements, explicit reference revisions, digest pins and cross-record context. A generic shape check, successful model construction or the existence of a containing object is not evidence that its fields are available. No coercion, default insertion or truthiness fallback may turn a missing prerequisite into an available value. Rules receive checked values through the same boundary; undeclared reads cannot support a clean result.

The boundary has exactly AVAILABLE(value), UNKNOWN(reason) and INTEGRITY_FAILURE(reason). Missing/null/unavailable required evidence is UNKNOWN; present malformed types, unsupported enum values, nonfinite/impossible numbers, corrupt payloads and failed integrity checks are INTEGRITY_FAILURE. Diagnostics carry the rule, exact subject revision, field/dependency path, state and reason. Multiple field failures may be recorded without changing the rule's one-finding-per-subject policy.

Applicability is itself checked. A valid explicit absence of an optional feature can establish that its dependent rule branch does not apply; an absent or null field that is required to determine applicability cannot. In particular, full-clip coverage does not bypass duration validation, and a present observation does not bypass dimension validation. Empty collections whose complete, validated contents prove a violation (no alternative, no warrant path, no residual) remain distinguishable from unavailable collections. A known violation can yield its named rule finding as well as a boundary diagnostic; only a clean result requires all applicable prerequisites to be AVAILABLE.

Minimum declaration and predicate inventory, to be expanded to concrete nested fields before L12-A is accepted:

- **E1 (error):** decision media/intent/binding pins, cited assessment pins and rationale/observations/evidence, or hypothesis relevance/criterion IDs, supporting evidence and warranted relations; exact target criteria/priority, media, intent revision and creative anchors. Traverse only valid scoped edges with visited identities. A fully available graph without a qualifying MUST/SHOULD path fires once per decision; a dangling edge cannot prove a clean path.
- **E2 (error), E2w (warning):** assessment status, observations, observation deviation and matching media/criterion, pinned intent/binding provenance. A SATISFIED material-or-worse deviation under RECONSTRUCTED/PROMPT_ONLY triggers E2; CONTEMPORANEOUS triggers E2w. Unknown deviation or provenance is not a lower severity or a sealed intent.
- **E3 (error):** evidence media/coverage, coordinate pairs and samples when applicable, matching ingestion media and usable decoded duration/frame timeline, and applicable derivative frame indices. Validate the timeline even for full-clip evidence. Interval end may equal duration; sampled instants must precede it; referenced frames must exist. Fire once per out-of-bounds evidence revision.
- **E4 (error):** relation version/predicate and typed purposes, using the local vocabularies; legacy free-text purpose is not a typed-purpose enum. Invalid values produce E4 and an integrity diagnostic, never a clean result.
- **E5 (error):** resolution frozen-plan/member/evidence pins and role prerequisites; or a confidence revision's exact predecessor, present old/new confidence and cited/new evidence with exact pre-revision hypothesis context. Fire for a nonempty all-DISCOVERY basis. Missing confidence or unavailable roles cannot support a clean result; no confidence arithmetic across claims.
- **E6 (error):** explicit freeze state, retained raw frozen payload, `frozen_digest` and the existing digest input fields. Verify raw data before normalization. A known mismatch fires E6 and prevents completeness; an unavailable prerequisite remains diagnostic. A validated draft is outside the frozen branch.
- **E7 (error):** explicit override presence and, when present, reason. Absent/null/empty/whitespace-only reason on a present override fires E7; wrong types are integrity failures. A valid declaration of no override is a separate branch.
- **W1 (warning):** exact hypothesis/observation context and dimension, support evidence pins, media type, coverage and applicable sample/interval data. Motion with nonempty still-only support fires W1. Missing typed context/coverage cannot become a non-motion result; valid non-motion context is supported without interpreting prose.
- **W2 (warning):** raw exhaustive flag, members and structural member kinds in the exact intent context. A hand-built exhaustive set lacking a residual fires before constructor normalization; lint never adds the residual.
- **W3 (warning):** exact hypothesis/intent, complete matching competing-set memberships and alternative relation endpoints. Require another distinct named hypothesis; self-links and residuals do not satisfy it.
- **W4 (warning):** arms and explicit generation-plan presence/pins, sample design, count-or-stopping condition and decision rule for generation-linked arms. Missing design/rule fires W4 and the corresponding availability diagnostic. Do not infer stochasticity from prose.
- **W5 (warning):** relation version and both typed purposes, or the explicit legacy compatibility view. Either UNSPECIFIED purpose fires once per relation. Corrupt v2 fields must not be converted into legacy UNSPECIFIED values.

The shared parameterized test enumerates every `(rule, prerequisite)` declaration with missing, null, wrong-type/malformed where representable, and a valid boundary value. It asserts the exact boundary state and field-specific reason. Maintain an independently authored prerequisite inventory/coverage assertion so deleting a declaration does not silently delete its test cases. For impossible-to-admit malformed cases use the same raw/read-only access path against isolated TEST-ONLY retained rows, not relaxed admission. B's dispatcher tests prove that unavailable prerequisites cannot be bypassed by a rule's clean or non-applicable branch; C exercises their propagation through retained query and external result state.
